# **2026-11-23 — Endnotes sidebar list item spacing (`EndnoteBlock`)**

----------------------------------------------------------------------------------------------------


## **What we worked on**

UX spacing on endnote rows in the right sidebar: padding inside the hover band, gutters from the card edge, and gap between the placeholder/copy row and citation body.


----------------------------------------------------------------------------------------------------


## **Components & files**

| Piece | Path |
|-------|------|
| List wrapper | `3_App/src/components/endnotesSidebar/EndnotesSidebar.tsx` |
| Line item | `3_App/src/components/endnotesSidebar/EndnoteBlock.tsx` |
| Reliable spacing + hover | `3_App/src/index.css` — `.endnote-block-item`, `__meta`, `__body`, `--editing` |

Reference pattern: `3_App/src/components/sectionSidebar/SectionListItem.tsx` (`p-3`, `hover:bg-[var(--bg-secondary-hover)]`).


----------------------------------------------------------------------------------------------------


## **Layout context (unchanged)**

- Sidebar `Card`: `padding="md"` → 16px inset; `bg-bg-secondary`, `overflow-x-hidden`.
- List: `space-y-1` (4px between rows).
- Parent does **not** crop row padding — missing side inset was a **styling** issue, not overflow.


----------------------------------------------------------------------------------------------------


## **Problem**

- Tailwind `px-2` / `py-*` / `hover:bg-bg-secondary-hover` on the row did **not** read as applied (see note in `3_App/src/index.css` that some Tailwind utilities are unreliable; prefer token-based component classes like `viewer-section`).
- Hover background filled the row box; without real padding, text looked flush to the grey band edges even when `mx-2` showed card gutters.


----------------------------------------------------------------------------------------------------


## **Final spacing (shipped)**

**`.endnote-block-item`**

- `padding: 0.625rem 1rem` — 10px top/bottom, **16px** left/right (inside hover)
- `margin-left/right: 0.5rem` — 8px gutter vs card inner edge
- Hover: `background-color: var(--bg-secondary-hover)`

**`.endnote-block-item__meta`** (placeholder uid + copy button)

- `margin-bottom: 0` — **no** gap between title bar and body (Nefko asked for 0)

**`.endnote-block-item__body`** (citation `<p>`)

- `margin: 0` — avoid default `<p>` spacing

**`.endnote-block-item--editing`**

- Same side margins; bordered edit card; `padding: 0.5rem`; white/`--bg-primary` background

`EndnoteBlock` read/edit shells use these classes instead of Tailwind padding/hover on the row.
